# Beispieldaten

`muster-grundbuchauszug.pdf` — vollständiger Muster-Grundbuchauszug: Amtsgericht
Musterstadt, Grundbuch von Muster Bezirk 11, Blatt 1119. Fünf Seiten: Deckblatt,
Bestandsverzeichnis, Abteilungen I–III.

Zusammengesetzt aus den Seitenbildern unter
https://www.docestate.com/grundbuchauszug-muster/ (abgerufen 2026-08-27).
Ausschließlich fiktive Daten (`Musterstadt`, `MusterReal International`,
`DocEstate GmbH Aschaffenburg`, `Daimlerstraße 42, 46`) — keine realen
personenbezogenen Daten.

## Warum dieser Auszug

Abteilung I führt zwei Eigentümer, von denen der erste
(`MusterReal International Real Estate Kapitalanlagegesellschaft mbH Hamburg`)
**nur durch Unterstreichung** als überholt markiert ist. Im OCR-Text sind beide
Einträge nicht unterscheidbar. Daran zeigt sich, ob der Agent das Seitenbild
heranzieht, statt einen gelöschten Eigentümer als aktuellen zu melden.

Andere frei verfügbare „Muster" (immoverkauf24, grundbuch24, direktantrag,
ihre-kostenlose-immobilienbewertung) wurden geprüft und verworfen: es sind
Marketing- oder Erklärbroschüren, in deren Tabellenzellen Beschreibungstexte
stehen statt Eintragungen.

Synthetische Varianten mit gezielten Fallstricken (gelöschte Belastung, mehrere
Eigentümer mit Anteilen, Zwangsversteigerungsvermerk, unvollständiger Eintrag)
werden separat per LLM erzeugt.
